# Minimalist SVG Template

**Used for:** modern brands, simple cut files, elegant designs.

```
Create a premium minimalist SVG design.

Requirements:
- simple recognizable shapes
- clean geometry
- strong visual identity
- balanced negative space
- limited elements

Avoid:
- unnecessary details
- complicated textures
- excessive decoration
```

**Caution:** minimalist designs face a higher differentiation bar —
fewer elements means less room to encode originality. Lean harder on
the Concept and Symbolic layers (`knowledge/ip-risk-and-originality.md`
§5) since Composition and Detail layers are intentionally limited here.
