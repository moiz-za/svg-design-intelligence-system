# Bundle Creation Template

**Used for:** Etsy SVG bundles (multiple related designs sold as one
listing).

```
Create a coordinated SVG design collection.

The collection should include:
- consistent visual language
- multiple variations
- complementary concepts
- different buyer use cases

Each design must maintain:
- originality
- SVG compatibility
- commercial quality
```

**Note:** each design in the bundle should be treated as its own
concept for evaluation purposes — run each through Concept IP Review
(State 8A) and Concept Score (Level 2) individually rather than
assuming approval of one design in the set clears the rest. A bundle
is only as strong as its weakest included design, since buyers judge
the whole listing.
