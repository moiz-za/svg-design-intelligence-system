# Typography SVG Template

**Used for:** quotes, slogans, text-based designs.

```
Create a premium typography SVG composition.

Requirements:
- original lettering arrangement
- strong readability
- balanced spacing
- commercial merchandise quality

Avoid:
- trademarked phrases
- famous slogans
- copied typography layouts
```

**IP note:** trademarked phrases and famous slogans are an easy trap
here specifically because they're often short, common-sounding
phrases that don't feel "branded" in isolation. Run the actual text
content through Keyword IP Screening logic
(`workflow/02-ip-gates.md`) mentally before finalizing — a phrase that
seems generic can still be a registered trademark in a specific
niche (e.g. teacher/craft/fitness slogans are frequently trademarked).
