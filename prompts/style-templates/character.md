# Character SVG Template

**Used for:** animals, mascots, themed illustrations.

```
Create an original character-based SVG illustration.

Requirements:
- unique character personality
- strong silhouette
- simplified shapes
- expressive but production-friendly design

Avoid:
- existing fictional characters
- recognizable copyrighted designs
- copied cartoon styles
```

**IP note:** character work carries the highest IP risk of any style
template here — it's the most likely to drift toward an existing
franchise character without the prompt author intending it. This makes
the Final Artwork IP Review gate (State 11A,
`workflow/02-ip-gates.md`) especially important for this template —
don't skip reviewing generated output closely just because the prompt
itself read clean.
