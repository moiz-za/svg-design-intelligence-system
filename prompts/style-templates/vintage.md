# Vintage SVG Template

**Used for:** badges, retro designs, heritage artwork, outdoor themes.

```
Create a premium vintage engraving-style SVG design.

Use:
- traditional printmaking aesthetics
- detailed line illustration
- balanced badge composition
- antique visual language

Requirements:
- monochrome black and white
- clean vector-style outlines
- strong contrast
- controlled details
- suitable for tracing

The design should feel like a collectible heritage emblem.
```

Pairs well with the Concept Transformation Method in
`knowledge/ip-risk-and-originality.md` §4 — vintage styling alone
isn't differentiation if the underlying concept is still generic.
