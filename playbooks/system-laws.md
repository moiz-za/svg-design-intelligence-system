# Playbook — Immutable System Laws & Execution Discipline

This playbook establishes the non-bypassable **5 Immutable System Laws** governing the Etsy SVG Design Intelligence System (ESVG-DIS). All AI agents, reasoning models, and portable single-file instructions MUST adhere strictly to these laws during workflow execution.

---

## 📜 The 5 Immutable System Laws

### ⚖️ Law 1: Immutable Pipeline Integrity
- **Directive:** Every workflow execution MUST process all 13 states, 4 IP gates, scoring levels, and 8 SEO listing phases sequentially without skipping, bypassing, or shortcutting any step.
- **Rule:** No state or gate may ever be simulated, glossed over, or silently ignored. Internal reasoning must process every check sequentially even when rendering a concise Caveman Mode output summary.

### 🔍 Law 2: Zero-Hallucination Evidence Traceability
- **Directive:** All research metrics, search volume ranges, competitor analysis, autocomplete suggestions, and trademark statuses must be grounded in empirical data or explicitly tagged.
- **Rule:** If live web search is unavailable or offline, qualitative estimates MUST be explicitly tagged with `[Data Source: Reasoning Engine Fallback]`. Never invent numbers, fake trademark registration dates, or fabricate search volume stats.

### 🛡️ Law 3: Binary IP Supremacy
- **Directive:** Intellectual Property risk screening is a hard binary gate (`PASS`, `MODIFY`, `BLOCK`).
- **Rule:** IP risk screening CANNOT contribute to or be averaged into commercial opportunity scores. High commercial potential or user preference can NEVER override an IP risk. If an IP violation is detected at Gate 1, 2, 3, or 4, execution MUST halt or pivot immediately.

### 🦣 Law 4: Caveman Output Protocol & Token Efficiency
- **Directive:** Output responses MUST be concise, high-density, bullet-first, and zero-fluff ("Caveman Mode") to minimize token consumption while maintaining 100% analytical depth in session state memory.
- **Rule:** Strip conversational preamble, repetitive introductions, and excessive prose by default. Full raw reports, detailed multi-column concept matrices, or deep prompt engineering rationale MUST remain preserved in state memory and rendered only when explicitly requested by the user (`"expand"`, `"full report"`, `"show details"`).

### 🏷️ Law 5: Native Listing Engine Mandate
- **Directive:** State 13 MUST natively execute all 8 Etsy SEO Listing Phases in a single pass without relying on external handoff summaries.
- **Rule:** Strictly enforce the Title Formula (`[Primary Keyword] [Style Descriptor] | [Format]`), Title Word Count Guardrail (6–12 words, max 14), Prohibited Subjective Words Stoplist (`cute`, `beautiful`, etc.), 13 Tags $\le 20$ chars each (max 2 tags sharing a phrase cluster), 8-Block Description, Etsy 2026 AI Creation Disclosure, Hero Alt Text, and Pinterest marketing block.

---

## ⛔ Non-Compliance Audit Signals
Any execution exhibiting the following defects violates the System Laws and MUST be corrected immediately:
- ❌ Skipping Intake, IP Gates, or Buyer Psychology states.
- ❌ Generating an artwork prompt without passing IP Gate 2 (Concept IP) and Gate 3 (Prompt IP).
- ❌ Outputting subjective filler words (`cute`, `stunning`, `perfect`) in titles.
- ❌ Omitting the Etsy AI Creation Disclosure settings in State 13.
- ❌ Outputting bloated, conversational prose when Caveman Mode is active.
